## Features
- Add, subtract, multiply and divide with correct operator precedence (2 + 3 × 4 = 14)
- Decimals, percent, backspace and all-clear
- Safe expression parser (no `eval()`), division by zero and invalid input handled
- Floating point fix (0.1 + 0.2 shows 0.3)
- Dashboard: total calculations, last result and recent history (saved in the browser, click an entry to reuse it)
- Keyboard support: 0-9, + - * /, Enter, Backspace, Esc
- Responsive CSS Grid layout with automatic light and dark theme
- Contact section for the developer

## Tech stack
HTML5, CSS3 (Grid, variables, media queries), JavaScript (ES6, localStorage)

## Project structure
```
index.html   dashboard, calculator, history and contact sections
style.css    layout and theme
script.js    calculator logic, history and stats
README.md    project documentation
```

## Run locally
Open `index.html` in any browser. No installation needed.

## Deploy (GitHub Pages)
1. Repo **Settings → Pages**.
2. Branch `main`, folder `/ (root)`, then **Save**.
3. Your site will be at `https://<username>.github.io/infobyte-calculator-dashboard/`.
